Scan a stack. Save one PDF.

An Obsidian plugin for scanners that save one file per page. Scan as usual, turn the wrong-way pages with a single key, and get one merged PDF in your vault.

Install Scan Stitch Source on GitHub

Made for scanners that think in pages

Many flatbed and sheet-fed scanners write IMG_0001.pdf, IMG_0002.pdf and so on into a folder, often starting over in a new folder every day. Turning that pile into one document, every page the right way up, is fiddly by hand. Scan Stitch watches the folder while you scan and hands you the finished PDF.

What it does

Pages show up while you scan

Start a session and feed the scanner. A side pane counts the pages and previews the last one as each file finishes writing.

  • Works with any scanner that saves PDF, JPEG or PNG files into a folder, including one subfolder per day.
  • Scanned a page twice? Discard last drops it from the session. The file itself stays put.
  • If Obsidian closes, the session is offered for resume next time.

Fix rotation with one key

End the session and the review screen opens on page 1: one large page and a filmstrip, all driven from the keyboard.

  • R turns a page clockwise, Shift + R the other way.
  • Shift+click a range in the filmstrip to turn a whole batch at once.
  • Drag thumbnails to reorder, Del to remove, Ctrl + Z to undo.

Saved where it belongs, named the way you like

Choose the destination when you start. Your last five folders are one click away, and named templates build the file name.

  • Placeholders such as {date}, {counter}, {pages} and {folder}, with a live preview.
  • Never overwrites: an existing name gets 2, 3 added.
  • Or append the new pages to a PDF already in your vault, verified before the original is replaced.

The review screen, by keyboard

Rotate, move and save without reaching for the mouse. On macOS, Cmd works wherever Ctrl is shown.

  • Rrotate clockwise
  • Shift+Rrotate back
  • ←→previous, next page
  • HomeEndfirst, last page
  • Delremove page
  • Ctrl+Zundo
  • Ctrl+Yredo
  • Ctrl+Aselect all
  • Entersave
  • Escback to scanning

Your scanner folder stays untouched

Scan Stitch reads files from a folder outside your vault, because that is where your scanner saves them. It is careful about it.

Read only outside the vault

It reads PDF, JPEG and PNG files from the scanner folder and never modifies, moves or deletes anything there. The Browse button in the settings uses your system's local folder picker.

Writes only into your vault

The merged PDF goes into the folder you choose. Nothing is overwritten.

No network, no telemetry

The plugin makes no network requests and needs no account.

Desktop only

Watching a folder outside the vault needs Node's file system access, which Obsidian has only on desktop. Windows is the fully tested platform; macOS and Linux are untested but expected to work.

Install

The Community plugins listing is pending review. Once it is listed, search for "Scan Stitch" in Settings, Community plugins. Until then, install it by hand:

  1. Open the latest release on GitHub.
  2. Download main.js, manifest.json and styles.css.
  3. Put them in <your vault>/.obsidian/plugins/scan-stitch/.
  4. Restart Obsidian and enable Scan Stitch under Community plugins.
  5. In its settings, set the watch folder to where your scanner saves.

Needs Obsidian 1.5.0 or newer on desktop; tested on Windows. Rotation is manual (no automatic detection), there is no OCR, and TIFF files are not read. Full documentation, settings, limitations and FAQ are in the README.
